# Prijem Robe — pilot bez prijave

Otpremi sadržaj ovog foldera u koren GitHub repozitorijuma i uključi GitHub Pages za `main` granu i `/(root)`.

- `index.html` — početni izbor MINI/PRO
- `mini.html` — mobilni prijem, imenovani spiskovi i CSV objedinjavanje
- `pro.html` — fizički prijem, CSV uvoz, OCR i poređenje sa otpremnicom
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA instalacija i keširanje stranica

Kamera zahteva HTTPS i dozvolu pregledača. Podaci se čuvaju lokalno u pregledaču ili prenose CSV fajlom; sinhronizacija između uređaja i prijava nisu uključeni.

**Repozitorijum i GitHub Pages su javni u ovom pilotu.** Ugrađeni katalog i otpremljeni fajlovi mogu biti vidljivi svima. Koristi samo testne podatke koje smeš javno da objaviš.
